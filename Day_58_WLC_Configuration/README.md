# Day 58 – Wireless LAN Controller (WLC) Configuration

## Objective
Practice configuring a **Wireless LAN Controller (WLC)**, creating WLANs, and connecting wireless clients.

---

## Lab Description
- Accessed **WLC1 GUI** via HTTPS from PC1  
- Explored WLC interface to understand network status and configuration options  
- Configured **dynamic interfaces** for Internal and Guest networks  
- Created **WLANs** with WPA2-PSK security  
- Connected a wireless client through an Access Point (AP)  

---

## Approach
1. Accessed WLC GUI using secure HTTPS connection  
2. Explored different tabs to understand system status, interfaces, and WLAN settings  
3. Configured dynamic interfaces for Internal and Guest networks  
4. Created WLANs and applied WPA2-PSK security  
5. Added a wireless client and associated it with an AP  
6. Verified client connectivity to the network  

---

## What I Understood
- WLC centralizes management of wireless networks and access points  
- WLANs define SSIDs and security settings for wireless clients  
- Dynamic interfaces map WLANs to specific VLANs/networks  
- WPA2-PSK provides secure wireless authentication  
- Wireless clients must associate with an AP to join the network  
- GUI tools simplify wireless configuration and monitoring
